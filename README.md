## 🌍 Overview

**UAP World Monitor** is an interactive web-based platform designed to visualize and explore reported UFO/UAP incidents from around the world.

The application combines:

- 🌎 Interactive world map
- 🛸 UAP incident database
- 🔎 Incident filtering
- 📅 Historical timeline
- 📸 Image galleries
- 🖼️ CoverFlow-style media viewer
- 📋 Detailed incident information
- ⚡ Lightweight static architecture
- 🚀 GitHub Pages deployment

The project is designed so that new incidents and media can be added **without modifying the core application logic**.

> **Add the data. Add the media. The application handles the rest.**
